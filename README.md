# LeNet-5 Pruning on Fashion MNIST

## Overview

This project demonstrates and compares two types of network pruning techniques—**Weight Pruning** and **Neuron Pruning**—on a LeNet-5 convolutional neural network (CNN) trained on the Fashion MNIST dataset. 

The script trains the model, applies pruning at various sparsity levels (the proportion of parameters removed), evaluates the accuracy of the pruned models, and compares their file sizes before and after compression.
